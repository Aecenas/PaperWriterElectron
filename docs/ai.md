# AI 功能说明

AI 功能包括供应商配置、AI 优化、完整信笺的 AI 协作、轻量选区问答和“帮助 → AI精灵”。AI 优化与 AI 协作记录会随 `.letterpaper` 文件保存；选区问答只在本次运行中保留；AI精灵多会话历史则独立保存在用户数据目录中。

## 供应商与模型

Gemini、DeepSeek、Qwen、Kimi、智谱 GLM、OpenAI、Claude、OpenRouter 和 Codex CLI 是内置供应商。用户还可以添加多个相互独立的自定义供应商：

- OpenAI 兼容：使用 Chat Completions 协议，Base URL 不应包含 `/chat/completions`。
- Anthropic 原生：使用 Messages API，Base URL 不应包含 `/messages`。

配置流程：

1. 从顶部 AI 入口打开 AI 设置。
2. 选择内置供应商，或点击“添加供应商”填写唯一名称、协议和 Base URL。
3. 在详情页填写 API Key，并添加模型名称和模型标识。
4. 逐个测试模型连接。
5. 将测试成功的模型设为默认。

没有已测试模型的供应商会显示未配置，不能设为默认或用于生成。内置供应商不可删除；自定义供应商可以删除，但默认项必须先切换。删除供应商会同时移除本机保存的密钥和模型配置。公开配置不会返回完整 API Key。

OpenAI 兼容请求使用 Bearer 鉴权并解析 Chat Completions SSE；Anthropic 请求使用 `x-api-key` 和 `anthropic-version: 2023-06-01`，将 system 消息提升为顶层字段，并把用量映射为现有的输入、输出和总 token 统计。

### 任务模型

“任务模型”可分别为“选区问答”“直接应用定位”“资料翻译”“AI 起稿”和“AI精灵”指定已测试模型；未指定时跟随默认模型，显式指定的模型失效时不会静默回退。每项任务使用独立折叠卡，重新打开 AI 设置时默认全部折叠；同一次设置会话中可同时展开多项并保留尚未保存的参数草稿。从任务模型错误提示进入设置时，会直接展开并聚焦对应任务。

## 资料翻译

资料阅读器支持右键调用“资料翻译”任务模型：PDF 翻译当前页，DOCX、Markdown、TXT、LOG、CSV 和 TSV 翻译当前标签内可读的全部预览内容，目标语言固定为简体中文。译文临时覆盖原文，不写入源文件或任何持久化状态。

- PDF 使用已有 pdf.js 文本层生成编号文本块，译文通过独立定位层覆盖相应区域；缩放后会重新测量位置，图片和页面尺寸保持不变。
- DOCX 与 Markdown 只替换可翻译文本节点，保留标题、列表、表格、图片、链接、公式和代码结构；纯文本保留换行；表格保留行列和纯数字单元格。
- 开始翻译会清除资料搜索；翻译中和已翻译时搜索不可用，取消翻译后恢复。PDF 翻页或搜索跳页、切换资料、关闭标签及应用退出都会取消请求并隐藏译文。
- 只有完整成功的译文才会写入本次应用运行期间的内存 LRU 缓存；再次翻译文本块完全一致的页面或内容时直接恢复，不调用模型。文本块内容、编号、资料类型、PDF 页码或目标语言变化都会形成新的缓存项，退出应用后缓存自然清空。
- 请求只发送块 ID、可读文字、内容类型、目标语言和 PDF 页码，不发送路径、文件名、原始 HTML、文件二进制或网页内容。图片、网页、扫描版 PDF、未知格式和资料区信笺首版不支持，也不进行 OCR。
- 正文总量上限为 200,000 字符；超过限制时不会发起模型请求。限制内按最多 12,000 字符或 100 个块依次分批；结构校验失败会修复重试一次，任一批最终失败则整次不应用译文。

## AI精灵

AI精灵是笺间自身的软件知识问答入口，只回答功能、操作、限制、故障恢复和隐私问题。每个问题都会提交给当前配置的模型；主进程先附带产品概览，再用当前问题和当前会话的近期消息检索相关知识，合计最多 6 个内置知识块作为 RAG 证据。检索结果不会决定是否调用模型；没有精确命中时，模型仍会依据产品概览和会话回答或追问。renderer 不能附加正文或其他上下文。只有问题明显不属于笺间时，模型才按系统提示说明支持范围。

- 知识库包含用户帮助主题和依据代码、测试核对的补充知识，随应用版本发布，不在线下载。
- 回答来源会标记为“帮助文档”或“补充知识”，点击后跳转到对应帮助主题。
- 同时只运行一个请求；关闭窗口或切换会话不会取消生成，停止后保留已有部分。
- 历史最多 50 个会话、每会话 200 条消息，单问题 8,000 字符、单回答 128,000 字符、总文件 32 MB；达到上限时要求用户处理，不静默删除。
- 每次请求只包含当前问题、当前会话最近 20 条消息、检索知识、应用版本和模型状态，不包含正文、路径、资料区、界面内容、其他 AI 记录或其他 AI精灵会话。
- 历史不写入 `.letterpaper`、恢复缓存或 `.jianprofile`，也不参与同步和配置迁移。
- Codex CLI 在新建的空临时目录和只读范围运行，完成后清理目录；HTTP 模型只接收上述最小上下文。

“选区 AI 小精灵”仍指选区问答最小化后的临时入口，与这里的持久软件知识问答相互独立。

## Codex CLI

Codex CLI 使用本机已经安装并登录的 Codex，不需要在笺间填写 Base URL 或 API Key。

1. 安装：`npm install -g @openai/codex`。
2. 在 Codex CLI 配置页点击“重新检查”。
3. 未登录时点击“登录 Codex”，在打开的终端完成授权。
4. 再次检查后，笺间会同步当前账号可用的模型和每个模型支持的推理强度。
5. 为各模型选择默认推理强度，再设置默认模型或默认供应商。

Codex CLI 仅在桌面端可真实调用。笺间不保存 Codex 登录凭据；模型、说明和推理强度以本机 CLI 返回的目录为准。刷新暂时失败但存在上次成功目录时仍可继续使用，并显示过期提示。

生成时每次创建独立临时会话，Prompt 通过标准输入传递，保留 `--sandbox read-only`、禁止审批、忽略用户规则与配置。Codex 可以读取本次允许范围内的项目文件，但不能修改文件；调用消耗当前登录账号的额度。

## AI 优化

AI 优化用于润色当前信笺、调整结构与表达：

- 定稿线以上作为已定稿背景，线以下是本次优化重点。
- 优化记录按信笺保存，退出 AI 模式或切换信笺不会清除。
- 开始新的优化会覆盖当前信笺已有结果。
- 清空优化只影响当前信笺，不会清除 AI 协作记录。

### 直接应用

优化模型只负责生成自由 Markdown，不承担原文位置标注。“直接应用定位模型”使用当前正文块清单、选中的优化块和相邻优化块判断替换或插入位置；正文修改始终由本地编辑器完成。

- Gemini、DeepSeek 定位请求固定使用 JSON 输出，并分别使用模型允许的最大输出上限；这个上限只代表最多可输出多少，不会要求模型实际输出到该长度。Codex CLI 通过提示词约束输出。
- 返回格式或位置字段错误时会自动修正一次；无法可靠定位、低可信度或网络失败时切换为“选择位置应用”。
- 手动模式可点选可编辑原文块，再选择替换、插入到前面或插入到后面；定稿区和保护块不可选，Esc 可取消。
- 定位成功后不会立即修改正文：待替换原文以红色显示，拟应用内容以蓝色显示，用户可直接在正文内确认或取消；插入操作只显示蓝色拟插入内容。修改方式、目标摘要和评注影响会一并显示。
- 只有在正文内确认时才产生一个编辑事务，可用一次 Ctrl+Z 完整撤销；取消对比不修改正文。定位期间若仅修改了无关段落，会尝试按目标原始内容和相邻上下文重新定位；目标本身变化或出现歧义时不会自动写入。
- 定位请求不包含工作区、研究资料、其他信笺、文件路径或完整 AI 历史。

## 轻量选区问答

普通写作模式和只读信笺中，框选文字后可点击悬浮工具条中的“问 AI”。每次点击都会冻结当时的选区并创建一个独立会话：

- 请求只包含冻结的选中文字、当前问题和这个会话的历史，不读取标题、其他正文、文件路径、图片、资料区或完整 AI 模式记录。
- 会话按信笺归属，同一信笺可在横向会话标签中保留并切换多个会话；移动到另一编辑组不会改变归属。
- 窗口可拖动或用标题栏方向键移动；选区快照默认只显示单行摘要，悬停或聚焦后才显示可滚动的完整内容。
- 最小化或按 Esc 会把窗口收起为所属信笺右下角的 AI 小精灵。后台生成不会被取消，小精灵会显示会话数、生成、未读和失败状态，点击即可恢复。
- 切换信笺或进入完整 AI 模式只会收起窗口，不会清除会话；明确关闭会话、关闭所属信笺或退出应用才会清理。会话不会写入 `.letterpaper`、自动保存缓存或工作区恢复数据。
- 每封信笺最多保留 10 个会话，全应用最多 50 个，最多同时生成 4 个会话；达到上限时需要先关闭旧会话。

## AI 协作

AI 协作沿用原完整信笺“AI 问答”的消息、草稿、模型切换和导出能力。同一输入框会先判断意图：普通问题继续围绕当前信笺流式回答；添加标题或 Emoji、整理表格、生成 Mermaid、改写正文、拆分或合并信笺等操作请求会生成结构化的待审阅方案。判断失败或意图不明确时必须由用户选择“仅回答”或“生成修改”。

- AI 不能直接修改文件。首版只允许修改当前信笺，或创建新的派生 `.letterpaper`；不会覆盖、删除、移动或重命名已有信笺。
- 操作代理只有“搜索当前工作区信笺”和“读取指定信笺快照”两个只读工具，最多 4 轮工具调用、读取 20 封信笺；实际读取清单会显示在协作回复中。
- 路径只使用当前工作区内的规范化相对路径；主进程拒绝绝对路径、`..`、隐藏应用目录和逃出工作区的符号链接。模型不会收到绝对路径或未命中的文件内容。
- 已打开且未保存的信笺优先使用编辑器实时快照。每个来源记录文档身份、正文指纹和磁盘版本，提交前会再次核对；外部变化会使方案过期。
- 方案仅允许标题、段落、标题块、列表、引用、分隔线、表格和 Mermaid；Emoji 作为普通文本。任意 HTML、脚本、文件路径和越权操作都会被本地校验拒绝。
- 拆分当前信笺可按来源块原样复制富文本；合并已读取信笺时复制来源正文，并只携带最终内容实际引用到的脚注和文献。来源文件保持不变，新信笺继承当前模板、获得新身份并清空评注和 AI 历史。

### 审阅与提交

- 每项当前信笺修改和每封派生信笺都可单独选择；拟应用标题、正文、表格、Mermaid、文件名和工作区内目标文件夹都可在临时审阅区继续编辑。
- 当前正文使用与“直接应用”一致的红色原文、蓝色拟应用内容对比，并在每张蓝色卡片内接受、拒绝或编辑。右侧只汇总总项数、已审阅数和“未审阅的全部接受”；审阅编辑不会触碰原文，全部逐项处理并最终提交后才会生效。
- 审阅期间停用继续提问、模型切换、清空记录和新的 AI 模式；当前信笺与所有实际读取的来源信笺保持只读，无关信笺仍可编辑。切换标签后可通过“返回审阅”回到原信笺。
- 提交当前信笺前创建“AI 协作前”历史版本，正文修改使用一个编辑事务。派生信笺先写临时文件，再通过提交日志统一落盘；失败会撤销当前事务并清理临时文件。
- 取消审阅不会修改正文或创建文件。待审阅方案会随信笺恢复状态保存，重启后绝不自动提交；版本不一致时只能取消或重新生成。
- 浏览器预览可模拟当前信笺的协作审阅；真实工作区搜索和派生文件提交仅在 Electron 桌面端启用。

### 当前信笺原图

目录范围菜单底部提供“信笺图片”：

- 原图：默认模式，保留正文中的 `[图N.标题]` 锚点，并按图号顺序通过 Codex CLI `--image` 附加全部原图。
- 仅标题：只发送图号和标题，不附加图片文件。

原图来自当前编辑器内存，支持未保存的 data URL 和已保存信笺的内嵌资源，不要求 Codex 自行读取或解包 `.letterpaper`。任一图片无法读取或格式无效时，请求会指出具体图号并停止；不会静默漏图或自动降级。临时图片在完成、失败或取消后都会清理。

HTTP 供应商仍只接收图片标题；原图模式只作用于 AI 协作中的普通问答，不改变 AI 优化或结构化操作方案。

## 保存与运行时回退

- AI 优化和完整 AI 协作状态随 `.letterpaper` 保存，复制信笺时会一起移动。
- 上述持久化 AI 状态变化会让信笺进入未保存状态，需要保存或等待自动保存；轻量选区问答不会改变信笺保存状态。
- 历史信笺引用的供应商或模型已不存在时，运行时回退到当前默认可用模型，不改写历史记录。
