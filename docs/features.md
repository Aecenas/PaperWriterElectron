# 功能总览

笺间围绕“文件组织、沉浸写作、智能辅助、可靠保存”设计。信笺使用 `.letterpaper` 格式，正文、素材、排版、评注和 AI 记录会一起保存。

## 文件与组织

### 工作区、左侧三栏与文件树

- 左侧栏以“文件 / 资料 / 结构”三个入口分别管理写作文件、独立研究资料和当前信笺的大纲、脚注、文献、书签等结构信息。
- 文件树支持展开文件夹、双击进入、打开信笺，以及拖动信笺到当前可见的文件夹。
- 文件和文件夹的创建、重命名、备份、移动与删除均使用应用内输入或确认弹窗。
- 大纲由正文的一至四级标题生成，可折叠并按标题编号导航。

### 标签页、打开队列与阅读位置

- 多个信笺可以同时打开，并通过顶部标签切换。
- 每个标签会记录自己的阅读位置；切走再返回时恢复上次滚动位置。
- 标签达到容量后继续打开信笺，会按打开队列腾出位置。
- 关闭标签不会删除文件；未保存信笺会先进入保存确认。

### 保存、恢复与导出

- 已保存信笺可直接写回，也可另存为新的 `.letterpaper` 文件。
- 未命名信笺会保存为临时会话，应用重启后可以恢复。
- 导出弹窗支持 PDF、分页图片、DOCX、Markdown、HTML 和 TXT，可选择目标位置并查看处理进度。
- PDF 和分页 PNG 共用当前页面布局；跨页后会延续全文图片与 Mermaid 图编号，落在段落中部的续页不会重复首行缩进。

### 资料阅读与临时翻译

- 资料区的 PDF、DOCX、Markdown、TXT、LOG、CSV 和 TSV 可在右编辑组以独立标签预览；PDF 保留每个标签的页码、缩放和滚动位置。
- 在阅读区右键或按 `Shift+F10` 可翻译 PDF 当前页或连续文档当前内容；完成后菜单变为“取消翻译”，取消会立即恢复原文且不修改源文件。
- PDF 翻页、搜索跳页、切换资料或关闭标签会停止翻译并隐藏译文；翻译中及已翻译时暂时不能搜索。
- 完整译文会保存在仅本次软件运行有效的内存缓存中；重新翻译文字未变化的同页或同一内容时直接恢复，不再次调用模型。内容变化会自动绕过旧缓存，退出软件即清空。
- 扫描版 PDF、图片、网页、未知格式和资料区信笺不支持翻译，也不会执行 OCR。单次正文最多 200,000 字符，超限内容不会发送给 AI。
- 资料翻译只发送编号后的可读文字块及内容类型，不发送路径、文件名、原始 HTML 或文件二进制；限制内会自动分批，只有全部批次成功才应用译文。

## 写作编辑

### 正文、标题编号与目录

- 标题、署名、日期和正文均可直接编辑。
- 正文支持一至四级标题、段落、列表、引用、对齐和撤销/重做。
- 标题层级同时驱动左侧大纲和正文目录；标题编号既可由模板控制，也可对当前标题单独启用或取消。
- 目录会按层级区分字号、颜色和缩进，标题仍保持正常的光标命中与编辑体验。

### 选区格式、链接与轻量 AI

- 选中文字后出现悬浮工具条，可设置加粗、斜体、下划线、字体颜色和水彩标注。
- 下划线提供实线、波浪线、虚线和双横线。
- 链接支持 `http`、`https` 与邮箱地址；已有链接可编辑或移除，移除链接不会删除显示文字。
- 点击“问 AI”会为冻结选区创建独立临时会话；同一信笺可保留多个会话，窗口可移动并可最小化为右下角 AI 小精灵继续后台生成。
- 选区问答只发送冻结选区、当前问题和本会话历史；会话只存在于本次运行中，不写入信笺或恢复缓存。
- AI 协作模式中可把选区加入“已标记文字”，作为下一次普通问答的重点上下文。

### 文档评注

- 框选文字后可新建评注，正文显示评注高亮，页面侧边显示对应锚点。
- 点击锚点可查看、编辑或删除评注。
- 评注范围会随正文变化进行映射，并随 `.letterpaper` 保存和复制。
- 同一位置评注过密时会限制继续添加，避免锚点重叠失控。

### 图片、音视频、引用与分页

- 媒体菜单支持图片、音频、视频和链接；图片可以调整宽度、编辑标题，并从悬浮图片工具中复制图号引用或直接删除。
- 音频文件上限为 20 MB，视频文件上限为 100 MB，素材会打包进信笺。
- 元素菜单支持引用块、分割线、分页符和表格。
- 模板可以控制图片标题和编号的显示；隐藏时标题文字仍会保留。

### 表格

- 顶部工具栏可插入默认表格。
- 光标进入表格后，上方出现表格工具条。
- 工具条支持在上/下插入行、在左/右插入列、删除当前行列或删除整表。

## AI 功能

### 供应商、模型与连接测试

- Gemini、DeepSeek 和 Codex CLI 是不可删除的内置供应商。
- 可创建多个自定义供应商，协议可选 OpenAI 兼容或 Anthropic 原生。
- 创建时填写唯一名称、协议和 Base URL，随后在详情页配置 API Key 与模型标识。
- 只有测试成功的模型才能设为默认并用于 AI 优化或 AI 协作。
- 自定义供应商可以删除，但默认供应商必须先切换；删除时密钥和模型配置会同步移除。
- 界面和公开配置只显示密钥遮罩或末四位，不返回完整 API Key。
- “任务模型”以默认折叠的独立卡片展示，可同时展开多项，为选区问答、直接应用定位、资料翻译、AI 起稿和 AI精灵指定专用模型或跟随默认模型。

### Codex CLI

- Codex CLI 复用本机安装和登录状态，不在笺间保存登录凭据。
- 配置页可检查安装、登录、CLI 版本和模型目录，并按模型保存推理强度。
- Codex 可用后可以设为默认，供 AI 优化和 AI 协作使用；浏览器预览仅展示配置，真实工作区读取与文件提交限桌面端。
- 每次调用使用独立临时会话、禁止审批并保持只读沙箱；允许读取的项目范围由当前功能决定。

### AI 优化

- AI 优化读取当前信笺并生成优化稿。
- 定稿线以上作为背景，线以下作为本次优化重点。
- 优化结果按信笺保存，可清空、重新生成或插入定稿线。

### AI 协作

- 同一输入框自动区分普通问答和操作请求；判断不明确时由用户选择，不会静默执行。
- 操作请求可修改当前信笺标题或正文，也可把拆分/合并结果创建为新的派生信笺；其他已有信笺始终只读。
- 工作区搜索和读取按需进行，最多 4 轮、20 封信笺；协作回复明确列出实际来源，模型不接收绝对路径。
- 标题、Emoji、表格、Mermaid 和正文块修改均在正文对应位置逐项显示并可接受、拒绝或编辑；右侧只汇总审阅进度，最终明确提交前不触碰原文。
- 审阅期间锁定当前信笺和所有实际来源，无关信笺仍可编辑；提交前创建历史版本并重新核对正文指纹、来源版本和目标文件冲突。
- 消息、输入草稿、待审阅方案和已解决摘要按信笺保存；重启后恢复审阅但绝不自动提交。

## 视图与效率

### 双编辑组与页面视图

- 左右两个编辑组各自管理活动标签、顺序和阅读位置；信笺可在组内排序或跨组移动，资料标签固定在右组打开。
- 右组可同时保留多个信笺和资料标签，拖动中间分隔线可调整宽度；关闭右组最后一个标签后恢复单栏。
- 每封信笺可独立使用连续、单页或双页视图；双页视图会暂时占用完整写作区域，切回后恢复原有双组布局。

### 系统模板与用户模板

- 系统模板只读，可预览并直接应用；切换模板不会改变正文、素材或评注。
- 可基于系统模板创建用户模板，编辑名称、封面简介、信纸背景、字体、字号、颜色、段落、标题编号和图片标题规则。
- 用户模板支持自定义分组、重命名、归类和删除；“我的模板”始终保留完整列表。
- 可指定新建信笺默认模板；默认模板被删除时会回退到上一项有效选择。

### 状态栏、缓存与更新

- 状态栏显示字数、段落、页数、图片、引用、自动保存时间和缓存大小。
- 缓存用于加速已打开信笺的编辑器结构切换，可手动清理。
- 更新入口位于右下角；发现更新时显示状态提示，检查失败或无更新后恢复为可点击状态。

## 帮助与 AI精灵

- 顶部“帮助”是只有“帮助文档”和“AI精灵”两项的下拉菜单。
- 帮助文档按文件与组织、写作与结构、资料与研究、AI 功能、视图与设置五类展示当前功能、步骤、注意事项与界面截图，并保留上次阅读位置。
- AI精灵提供本机多会话软件知识问答，支持新建、切换、重命名、删除、停止、重试、复制和来源跳转。
- 每个问题都会进入已配置的 AI 模型；产品概览和按问题检索的知识仅用于 RAG 增强，不以检索命中与否决定是否回答。
- AI精灵只使用随版本发布的帮助知识、代码核对知识和自身近期会话，不读取信笺正文、文件路径、工作区、资料区或其他 AI 记录。
- 关闭 AI精灵不会停止后台回答；完成后显示状态提示，重新打开仍可查看历史。
