# Bookmark assets

All bookmark variants share the same `80 × 160` transparent SVG canvas and silhouette, so they can be swapped without changing layout.

- `bookmark-teal-woven.svg` — default; closest to the large teal linen bookmark mockup.
- `bookmark-teal-stitched.svg` — woven teal with understated ivory stitching.
- `bookmark-teal-brass.svg` — woven teal with a slim antique-brass backing edge.
- `bookmark-teal-washi.svg` — flatter, softer handmade-paper texture.

The active asset is selected by `--paper-bookmark-asset` in `styles-professional-content.css`.
